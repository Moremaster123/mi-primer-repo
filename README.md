# Mi primer repositorio: calculadora en Python

Calculadora de consola que pide dos números y muestra la suma, la resta, la multiplicación y la división. Fue mi primer repositorio de Python en GitHub.

## Tecnologías

- Python 3

## Cómo ejecutarlo

```bash
python calculadora.py
```

Ejemplo:

```
=== Calculadora sencilla ===
Escribe el primer número: 8
Escribe el segundo número: 2
8.0 + 2.0 = 10.0
8.0 - 2.0 = 6.0
8.0 x 2.0 = 16.0
8.0 / 2.0 = 4.0
```

Si el segundo número es 0, la división muestra un mensaje de error en lugar de fallar.
